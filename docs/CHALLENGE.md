# Confirmed challenge brief

For current requirements and the selected battery case, see [PROJECT_PLAN.md](../PROJECT_PLAN.md) and the [organizer's dossier v1.6](../MRI_Local_Spectroscopy_Health_Digital_Twin_Hackathon_Dossier_v1.6.pdf). This page records the early event brief.

Source (Ulm University official page, last modified 2026-11-06):
https://www.uni-ulm.de/en/io/degree-phd/students/fit4u/community/vernetzung/hackathon/

**Challenge:** NMR Quantum Engineering: From Spins to a Health Digital Twin — for People, Devices and Objects. Partners: Ulm University, CTU Prague, TU/e.

**Input:** Starter pack with *synthetic* MRI and spectroscopy data, an interactive MRI Data Explorer, and a challenge dossier with worked examples.

**Task:** Build a prototype twin from a baseline and follow-up MRI/MRS session of one system. Decide which changes are real and which arise from measurement; update the twin with honest uncertainty; recommend what to measure next.

**Output:** A working prototype, a machine-readable evidence packet, and a **five-minute pitch** defending one twin update: what changed, how certain, and what to measure next. Dossier v1.6 §9.11 allows synthetic, public, de-identified, or instructor-prepared data.

**Support:** Mentoring in quantum engineering, precision mechanics, data science, and digital twins; per-team mentor assignment is not stated.

**Schedule:** Fri 20 Nov: MRI/MRS lecture 10:00–13:00; hackathon kick-off 16:00 with on-site team formation/matching; Sat 21 Nov: pitch review 13:30, final pitches 15:00, awards 16:00, event ends 17:00. Lecture location is not stated on the page.

**Not confirmed:** Dataset format, sample sizes, uncertainty calibration, ground truth, scoring criteria, code reuse rules, dual-team participation, data release date.
