# On-site runbook

## Friday: lecture and kick-off

1. Attend 10:00–13:00 MRI/MRS lecture. Write down the data representation and uncertainty sources.
2. At 16:00, verify team assignment, code-reuse and cross-team contribution rules.
3. Obtain organizer dossier/data/Explorer instructions. Save the original files outside Git (data/).
4. Inspect shapes, units, identifiers, baseline/follow-up pairing, metadata and missing values.
5. Ask mentor how measurement uncertainty and ground truth are defined. Record the answer.
6. Choose the *smallest scientifically defensible* twin state and one meaningful update.

## Build order

1. Reproducible input reader and a minimal baseline/follow-up report.
2. Uncertainty assumptions and change test; include an explicit 'inconclusive' outcome.
3. State update and uncertainty propagation.
4. Next-measurement recommendation with a clear reason.
5. Machine-readable evidence packet, limitation statement, and a live demo.

## Saturday deadline

- 13:30 pitch review: functioning end-to-end demo and preliminary evidence packet.
- 15:00 final pitch: five minutes; explain the change, confidence and next measurement.
- 16:00 awards. Event ends 17:00.

Keep a known-good run command in the README once implementation begins.
