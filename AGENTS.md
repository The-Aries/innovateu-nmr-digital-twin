# Working rules

- Read README.md and docs/DECISIONS.md first.
- Treat the organizer's dossier (`materials/organizer/`) and the published Bray et al. (2020) data as authoritative.
- Keep downloaded third-party data, local outputs and secrets out of Git. Add only verified results to `evidence/`.
- Record provenance and assumptions for all analysis. Label simulated values as simulated.
- Prefer simple, inspectable statistical methods with documented validity over unvalidated ML.
- Do not reuse code or proprietary resources from other challenges without explicit permission.
- Run the `rmdi-dashboard` tests before changing results in `evidence/`.
