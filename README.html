InnovateU 2026 — NMR Digital Twin

Private project workspace for the NMR Quantum Engineering challenge (20–21 November 2026, KICU Ulm).

Scope

The challenge asks teams to demonstrate a traceable baseline-to-follow-up update, distinguish physical change from measurement effects, communicate uncertainty, and propose the next measurement. The organizer's dossier v1.6 specifies the deliverables and permits public and synthetic data.

Project plan and decisions maps the four tracks and submission tasks to the Birmingham Figure 5 case.

Project files

  • Birmingham Explorer follows the measured ²³Na series and the corresponding electrochemical record for the main case. The cross-device time offset is provisional.
  • Organizer's MRI Data Explorer opens the synthetic MRI/MRS teaching case.
  • Chinese materials index links the translations to the organizer's original documents.
  • Organizer's StarterPack archive contains the full synthetic teaching package. Extract it to restore the MRI and MRS example files alongside those already in the StarterPack directory.
  • Bray et al. (2020) is the paper for the main case. See the Birmingham case walkthrough and background references.

Repository updates

Make changes in the local project checkout, regenerate any affected companion HTML, and verify the changes locally. Commit and push through Git. For another checkout of the same branch, use git pull --ff-only origin main to receive the tracked updates. Download the experimental data separately in each checkout that needs it.
