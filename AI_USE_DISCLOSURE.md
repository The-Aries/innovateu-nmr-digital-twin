# AI Use Disclosure

We used ChatGPT to help summarize background literature and draft project documentation. We used OpenAI Codex and Claude Code to help develop and debug the Birmingham NMR Explorer and the code used to generate the synthetic dataset. The team checked the scientific claims against Bray et al. (2020) and tested the earlier Figure 5 workflow with the published experimental dataset. The final Battery Twin Explorer v1.1 displays published spectra from Figures 6 and 7 as measured examples alongside its simulated cycling case.
